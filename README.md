# 分子透射零点能否在弱位点扰动下恢复？

一个分子原本在给定能量下透射为零。如果几个原子的位点能都只能升高，能否让它们在**全部升高、且升幅任意小**时再次精确抵消？这份理论化学研究稿给出了一个带符号的路径判据，并在径向烯（radialene）模型上求出了恢复零点所需的位点能。稿件包含模型内的证明和有理数检验，尚待独立审阅、完整查新和投稿。[英文研究稿（PDF）](weak_gating.pdf) · [LaTeX 源码](weak_gating.tex) · [分子结构与补偿曲线](radialene_figure.pdf)

## 一个可以手算的例子

取 [5]radialene 的十个碳 π 轨道，每个碳一个轨道，初始位点能为零，最近邻跃迁为 $-1$，固定电子能量 $E=0$。把两个电极接在环外碳上，使它们对应的两个环碳沿短弧相距两键。其余三个环外碳中，短弧上的一个位点升高 $x$，长弧上的两个位点各升高 $y$。接点间孤立分子格林函数的精确表达式为

$$
G_{st}(0)=x-\frac{y^2}{1-y^2}.
$$

当 $y=1/10$ 时，$x=1/99$ 给出零点，$x=y=1/10$ 则给出 $G_{st}=89/990$。沿任一固定正比例 $x=cy$ 向原点扫描，都会错过附近的零点，因为两条弧的贡献分别从一阶和二阶开始。母体分子的合成已有报道，这里的输运结果来自模型计算。[母体分子的合成论文](https://doi.org/10.1021/jacs.5b07445)

## 一般判据与径向烯的奇偶效应

设 $H$ 为有限实对称单粒子哈密顿量，$g=(EI-H)^{-1}$ 存在，两个不同接点满足 $g_{st}=0$。选定可调的非接点位点并给每个位点能移指定正负方向。在这些位点与两接点上作图，两个不同顶点 $i,j$ 在 $g_{ij}\ne0$ 时连边。对每条从 $s$ 到 $t$ 的无弦路径，将沿途各边的 $g_{ij}$ 与所有内部位点的扰动符号相乘，得到路径权重。无弦指路径上任意两个不相邻的顶点之间都没有额外的边。

| 无弦路径的权重 | 对传输零点的结论 |
| --- | --- |
| 没有路径 | 只扰动这些位点时，在逆矩阵存在的范围内零点始终保留。 |
| 至少一条路径，且权重全部同号 | 各位点在指定方向上都受到充分弱的非零扰动时，零点必然打开。 |
| 两条路径的权重异号 | 在任意小的扰动范围内，都可使全部选定位点受到非零扰动，并让接点间格林函数精确归零。 |

证明用到了格林函数分子中的余子式。每条无弦路径恰好对应一个按包含关系最小的非零单项式，其系数就是路径权重。对每端一个局域接点的相干输运，这个格林函数零点也是固定能量下的透射零点。[定理及证明](weak_gating.pdf)

对最近邻 $[n]$radialene，将接点置于两个对应环位不相邻的环外碳。设两弧各有 $p,q$ 个内部位点，两组环外位点的共同正向能移分别为 $x,y$。奇数环在与原点相邻的无极点区域内有唯一补偿曲线，近原点满足 $x\sim C y^{q/p}$。改变原有各键的跃迁强度、保持其符号时，系数 $C$ 可变，指数 $q/p$ 保持不变。偶数环在充分弱的全正扰动下具有非零透射。结论涉及固定能量下的相干传播；室温电导还要对能量窗口内的透射作热平均。

## 复现计算

精确验证使用 Python 3.8 或更高版本，只依赖标准库。在仓库根目录运行下列命令，第二条命令无输出并返回 0 表示与保存的记录逐字一致。[验证程序](verify.py) · [预期输出](verification.txt)

```sh
python3 -B verify.py > /tmp/radialene-verification.txt
diff -u verification.txt /tmp/radialene-verification.txt
```

程序枚举 2 至 6 个顶点、最大度数为 3 的连通简单图，按同构去重。对其中可逆的邻接矩阵和未扰动时格林函数为零的接点对，共检验 8,118 种位点及符号配置。另用完整分子矩阵在 180 组有理参数上核对双弧公式，并对五至十五元的六个奇数环模型检查精确零点。一次本地运行约 1 秒。

**次近邻跃迁的敏感性。** 固定 $y=1/10$，在承载两接点的环碳 0 和 2 之间增加一条跃迁。下表的 $\delta$ 表示这条边在 $M=-H$ 中的矩阵元，以原最近邻跃迁大小为单位。每个表项都通过完整矩阵的余子式求根并检验分母非零。

| 骨架 | 理想模型的补偿值 $x$ | 加入 $\delta=1/100$ 后的补偿值 $x$ |
| --- | ---: | ---: |
| [5]radialene | 1/99 | 199/9900 |
| [7]radialene | 1/9701 | 9801/970100 |

七元环所需的 $x$ 变为原值的 **98.01 倍**。这个算例量化了额外跃迁对曲线位置的影响，也说明在这两个体系中重新调节后仍可达到零点。复现命令如下。

```sh
python3 -B - <<'PY'
from fractions import Fraction as Q
from verify import cofactor, determinant, green, radialene, shifted

for n in (5, 7):
    for delta in (Q(0), Q(1, 100)):
        matrix = radialene(n, [1] * n, [1] * n)
        matrix[0][2] = matrix[2][0] = delta
        s, t = n, n + 2
        gates = {n + i: Q(1, 10) for i in range(3, n)}

        def numerator(x):
            return cofactor(shifted(matrix, {**gates, n + 1: x}), t, s)

        a, b = numerator(0), numerator(1)
        x = a / (a - b)  # 余子式对单个位点能 x 是仿射函数
        gates[n + 1] = x
        assert determinant(shifted(matrix, gates)) != 0
        assert green(matrix, s, t, gates) == 0
        print(n, delta, x)
PY
```

仓库已附论文和图的 PDF。重绘图需要 NumPy 和 Matplotlib；从源码构建论文需要含 pdfLaTeX 的 TeX 环境。若复用仓库中的图，可直接从两条 pdfLaTeX 命令开始。[绘图程序](make_figure.py)

## 原创性与投稿定位

已有工作用格林函数逆图的最短路判断打开零点所需的最低扰动阶数，也已有针对未扰动径向烯的导电图和余子式的路径展开。本稿最值得和前人逐条比较的是两个结论：指定各位点扰动方向、允许扰动幅度以不同速率趋零时的充要判据，以及径向烯补偿曲线的唯一性和指数 $q/p$。[最短路规则](https://doi.org/10.1088/1361-648X/add77f) · [径向烯导电图](https://doi.org/10.46793/match.93-2.379B) · [余子式路径展开，命题 3](https://doi.org/10.1111/sjos.12604) · [官能化分子的图解干涉规则](https://doi.org/10.1039/C1CP20924H)

目前对 Niţă 等 2022、2023 年两篇 *Physical Review B* 论文的核对限于摘要。尤其需要核清后者的多位点逻辑门条件是否已涵盖上述符号判据。如果判据已有等价表述，投稿价值取决于径向烯族的补偿定理还能提供多大增量。[2022 年论文](https://doi.org/10.1103/PhysRevB.105.155303) · [2023 年论文](https://doi.org/10.1103/PhysRevB.108.235307)

### MATCH 路线

1. **完整查新与独立审证明，6–10 人时。** 先核清两篇 PRB 全文，邀请熟悉线性代数或分子输运的读者检查“当且仅当”两个方向。若发现等价定理，先重估稿件的原创贡献。
2. **敏感性计算，6–12 人时。** 在五元和七元环上分别扫描入射能量和弱次近邻跃迁，追踪 $x_\star(y)$。将上表的单点算例扩展为曲线，标出离开最近邻或零能假设后偏移的尺度。
3. **改稿与复现，8–18 人时。** 增加逐项文献比较和适用边界，加入敏感性图，用 MATCH 模板排版，再由独立读者复跑示例。

### PCCP 路线

1. **第一周先试一个 [5]radialene 体系。** 优化几何，构造两种空间分布不同的局部静电扰动，分别在零场及正负小场做密度泛函理论（DFT）单点计算。在同一局域轨道基底下，提取两弧有效位点能对两种控制的响应，并检查键跃迁的变化。如果两种响应近乎共线，或跃迁变化主导输运，优先调整调控方案。先计时一次几何优化和一个有限场单点，再校准核时预算。
2. **若两种控制可以独立调节两弧，追加 2–4 周。** 加一个偶数环对照，选代表性参数复核基组或泛函，从分子哈密顿量计算透射谱 $T(E)$。比较零点位置、能量失谐后的谷深以及室温热平均电导反差。预算规模约为两套小分子几何和十几至几十个单点。
3. **分析和写作，1–2 周。** 量化热展宽、额外跃迁和调控串扰各自在什么尺度上掩盖干涉。当前仓库的计算限于模型与有理数核验；DFT 几何、有限场响应、热平均结果和实际核时均待计算。
